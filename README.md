# 🩻 MedVision-AI

An AI-powered pneumonia detection and chest X-ray analysis system combining CNN-based image classification with GPT-powered medical reporting.

## 📖 Overview

MedVision-AI uses a Convolutional Neural Network (CNN) to classify chest X-ray images as Normal or Pneumonia. It integrates OpenAI's GPT vision capabilities to independently analyse the X-ray, compare its assessment with the CNN prediction, and generate a detailed report.

## ✨ Features

- Chest X-ray classification using CNN.
- Detects Normal and Pneumonia cases.
- GPT-powered independent X-ray analysis.
- Compares CNN predictions with GPT assessment.
- Generates detailed AI-assisted reports.
- Interactive interface built with Streamlit.

## 🛠️ Technologies Used

- **Python** – Core programming language.
- **TensorFlow / Keras** – CNN model development.
- **OpenAI API** – GPT-based X-ray analysis and reporting.
- **Streamlit** – Interactive web application.
- **NumPy & Pandas** – Data processing.
- **Matplotlib** – Visualisation.

## ⚙️ Project Workflow

1. Upload a chest X-ray image.
2. CNN predicts Normal or Pneumonia.
3. GPT independently analyses the X-ray.
4. Both assessments are compared.
5. A detailed AI-generated report is displayed.

## 🎯 Objective

To demonstrate how deep learning and generative AI can be integrated to support AI-assisted chest X-ray screening and reporting.

**Disclaimer:** This project is for educational and AI-assisted screening purposes only. It is not a substitute for professional medical diagnosis. Final clinical decisions must always be made by a qualified healthcare professional.
